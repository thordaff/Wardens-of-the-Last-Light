# assets/characters

Satu folder per karakter, nama huruf kecil: `assets/characters/aldric/`, `assets/characters/seren/`, dst.

Art yang sudah ada di folder lokal (`art/characters/aldric/`) dipindah ke sini: `assets/characters/aldric/`.
Sprite 32×48 px, import PNG dengan filter Nearest, mipmaps off (art-direction.md §7.1).
